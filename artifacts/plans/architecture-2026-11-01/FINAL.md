# Koi 1.0.0 architecture — final handoff

Status: **complete** on branch `koi-engine` at `33f9b08` (code head `cf606cc`).
This is the stable 1.0.0 architecture that should remain until 2.0.0. No version
bump, tag, or release was made; `1.1.5` remains at `1e09504`.

## Scope

The work was an architecture pass, not a redesign:
- audit layering, dependencies, ownership and dead code;
- make conservative, test-backed structural refactors;
- document the resulting contract and enforce it mechanically;
- keep signed commits, a clean worktree, and green CI.

The user stopped the reliability program before this pass (the 1M soak was
terminated at 730,710 rounds); this pass did not resume reliability fuzzing.

## Implemented

Compiler/API boundaries:
- `hash_types.hpp`: hash-policy/result values no longer pull the TT definition
  into `SearchService` consumers.
- `uci_controller.hpp` forward-declares `detail::DebugLog` and `SyzygyTablebase`
  (no `<fstream>`/tablebase header in the public controller header).
- `search_types.hpp` forward-declares `GameState`; its one rules-dependent
  function moved to `search_types.cpp`.
- Public headers rejected for heavy includes (`<fstream>`, `<iostream>`,
  `chess.hpp`, `tbprobe.h`, `<cuda.h>`) by the architecture test.
- `SearchService` is a **move-only value** (copies would alias TT/evaluator).

Component/policy extraction:
- `detail::root_fallback.{hpp,cpp}`: bounded root-fallback policy extracted
  from the driver (`search_runner.cpp` 5,307 → 2,725 lines).
- `detail/search_worker_pools.hpp` + `detail/search_stats_support.hpp`: Lazy-SMP
  and root-parallel worker ownership, abort/failure capture, live stats.
- `detail/uci_option_table.hpp`: the 28-entry UCI option catalog; shared bounds
  centralized in `detail/search_constants.hpp`.
- `detail/fen_validation.{hpp,cpp}`: stateless FEN syntax validation.
- `detail/game_state_impl.hpp` + `detail/native_check_probe.hpp`: the private
  `GameState::Impl` and move-check probe inputs moved out of the facade TU.
- `detail/consistency.cpp`: native/shadow consistency-diagnostic snapshot
  builder, friended by `GameState`.
- Option normalization moved into `SearchService` (runner no longer owns it).
- `detail/debug_log.{hpp,cpp}`: best-effort JSON debug log behind the controller.

Ownership/error model:
- Explicit `SyzygyLoadStatus` (including `path_conflict`), instead of reporting a
  path conflict as “no usable tables”.
- Typed `SearchFailureReason` and a `info string search failed (<reason>); using
  a safe fallback move` diagnostic before a failed fallback bestmove.
- `SearchService` evaluator configuration guarded against concurrent `start()`.
- Setup-prefix failures keep the request identity so the completion gate can
  emit a legal fallback instead of suppressing the only bestmove.
- Non-blocking `TranspositionTable::try_set_size_mb`: new storage is published
  immediately; pinned retired storage is retained and reclaimed later
  (`HashResizeResult::reclamation_deferred`). `SearchService::start` uses it;
  the blocking resize and UCI stop/join semantics are unchanged.

Test/tooling structure:
- Dead `move_chooser` removed; benchmark fixtures moved to `koi_strength_suite`.
- Reliability fuzzers moved from `artifacts/` to `tests/python/reliability/`.
- Test-only synthetic NNUE fixtures moved to `tests/support/nnue_synthetic.*`;
  test-only controller construction moved to a test-support factory.
- Generated bytecode/build caches untracked; `.gitignore` extended.

Documentation/guards:
- `docs/ARCHITECTURE.md`: dependency direction, ownership/threading, fail-closed
  policy, test layout, and the stability contract for 1.0.0.
- `artifacts/plans/architecture-2026-11-01/{AUDIT,VERIFICATION}.md`: findings,
  implemented items, verification evidence.
- `koi_architecture_boundaries` CTest enforces public-header seams, protocol
  purity (single writer), option-catalog ownership, shared bounds, no artifacts
  in the build graph, header hygiene, and test-support separation.
- Stale `CONTRIBUTING.md` facts (branch, classical evaluator, CI matrix) fixed.

## Verification

- Release: full build; complete local CTest matrix (heavy included) passes apart
  from the known local Python environment/timing failures.
- ASan: unit 24/24; reliability 8/8 (804.9 s / 899.7 s / 743.6 s on successive
  final trees), zero AddressSanitizer/SEGV reports.
- Modules-enabled (`KOI_BUILD_MODULES=ON`) full non-heavy suite passes;
  `koi_module_tests` passes with runtime contract-default assertions.
- Shadow-diff configuration builds and `koi_shadow_diff_tests` passes.
- Mac arm64: direct clone build + core CTest 4/4 (GitHub macOS runner is
  infrastructure-cancelled, including manual dispatch).
- CI: Windows and Linux full matrices green on watched heads `cf606cc`,
  `33f9b08`; docs green. macOS jobs are cancelled ~1 s after creation by the
  runner, independent of code.

## Out of scope for this pass (2.0.0)

- Splitting `koi_core` into `koi_rules`/`koi_eval`/`koi_search`/`koi_uci`.
- Splitting the single ~2.6k-line `SearchRunner::run_impl` into serial and
  root-parallel drivers.
- Evaluator/search architecture redesign; GPU NNUE remains experimental.
- Any version bump/tag/release.

## Resume points

- `docs/ARCHITECTURE.md` is the contract to preserve.
- Run `ctest -R koi_architecture_boundaries` before/after structural changes.
- Evidence and CI head IDs are in `VERIFICATION.md`.
