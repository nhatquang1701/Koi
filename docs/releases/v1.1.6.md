# Koi Engine v1.1.6

Released 2026-11-08. This release delivers a major search depth and node-efficiency
overhaul, a clean rewrite of the hand-crafted classical evaluator (`EvalMode=hce` /
`KOI_EVALUATOR=hce`), extensive UCI protocol and optional-asset reliability
hardening, a custom CC0 Lichess-database opening book, Syzygy tablebase
auto-discovery, and the 1.0.0 architecture boundary cleanup.

## Highlights

- **Search depth and node-efficiency overhaul (+650 Elo cumulative in `1+0` SPRT).**
  - **Interior beta cutoffs, TT bound stores, and history updates (`e77dba9`):**
    Restored standard fail-high cutoffs (`best_score >= beta`), `TranspositionBound::lower` /
    `exact` / `upper` interior TT stores, and quiet/capture history bonuses and
    maluses when `root_ply > 0`. Reduced depth-6 middlegame nodes by **32.4x**
    (`21,416,117 -> 660,061`) and passed the Mac `1+0` clock SPRT at 60 games
    (**+55 =5 -0, 95.83 %, +544.7 Elo, LLR +20.05**; average depth `5.27 -> 9.99`).
  - **Quiescence fail-low TT upper bounds and check horizon (`5f1d82a`):**
    Cached fail-low quiescence results as `TranspositionBound::upper` with upper-bound
    TT cutoffs (`entry->score_cp <= alpha`) and tightened `kMaximumQuiescenceCheckDepth`
    from `3` to `2`. Reduced depth-7 middlegame nodes by **3.32x** (`5,708,524 -> 1,720,992`)
    and scored **54.37 % (+30.5 Elo)** in an 80-game 200 ms screen.
  - **Interior pruning and IIR/IID unblocking (`51ba6e6`):**
    Removed blanket `tactical_position()` lockouts that disabled Reverse Futility
    Pruning, Null Move Pruning, ProbCut, Razoring, Futility Pruning, Late Move
    Pruning, and IIR/IID whenever any legal capture existed, relying instead on
    in-check guards, quiet-move gates, and SEE filters. Brought cumulative
    depth-6 middlegame contraction to **302.1x** (`21,416,117 -> 70,881` visited
    nodes, reaching depth 9 in `540,101` nodes) and passed the Mac `1+0` clock
    SPRT at 201 games (**+98 =67 -36, 65.42 %, +110.8 Elo, LLR +2.96**; average
    depth `10.18 -> 11.46`).
  - **Hot-path speedups (`6fc1255`, `b2a142c`, `d9e4e3d`, `f55fc90`, `8e9f999`, `4f7d1ce`, `d49ce0f`):**
    Reused precomputed king slider rays in `native_move_gives_check`, deferred legal
    move generation past early negamax cutoffs, used bitboard attack tables in
    pre-move forcing probes, vectorized sparse NNUE accumulator refresh and the v5
    head with AVX2, reused the refresh sums buffer, and skipped unused v4 threat
    slot copies. Added `--iteration-profile-json` to `koi-bench`.
- **Clean HCE rewrite and runtime `EvalMode` (`4d13392`..`a1ff6b4`).**
  Added a clean, native-position tapered hand-crafted evaluator (`src/koi/classical_evaluator.*`)
  selectable via the `EvalMode` UCI option (`nnue` default, `hce`) or the
  `KOI_EVALUATOR=hce` boot variable, plus `--hce` support in `koi-bench` and
  `koi-eval-features`. Experimental GPU NNUE was completely removed (`5e1457b`).
- **Custom CC0 opening book and Syzygy auto-discovery (`34f43f6`, `ebc4662`, `c20c3a7`, `686c066`).**
  - Replaced the bundled `book/koi.bin` with a custom CC0 1.0 Polyglot book built
    by `tools/book/build_database_book.py` from 4,084,023 Lichess standard games
    (35,606 strong rapid/classical games, 47,020 entries, 752,320 bytes, SHA-256
    `2ee7643d193a...`).
  - Added automatic discovery of `syzygy/`, `syzygy345/`, `tablebases/`, or
    `3-4-5/` directories beside the executable when `SyzygyPath` is unset, with
    magic-header, canonical-size, zero-payload, and path-list sanitization before
    passing paths to Fathom.
- **UCI protocol and reliability hardening.**
  - Fixed GUI analysis score omission (`9d9648e`) so `info` lines always publish
    the iteration score (fixing 0 cp displays in En Croissant) and paired interim
    `currmove` with `currmovenumber` (`0ace50b`).
  - Bounded UCI input lines to 1 MiB (`2706418`), ignored `SIGPIPE` on broken GUI
    pipes (`9e9e261`), hardened non-regular/unreadable `EvalFile`, `BookFile`,
    `SyzygyPath`, and `DebugFile` handling, and added deterministic and randomized
    fuzzers plus long-running resource/option-churn soaks (`ctest -L reliability`).
- **Architecture and packaging cleanup (`270b77a`, `31dce76`, `0e45adb`).**
  - Release archives now ship **engine binaries and runtime assets only**
    (`koi-engine` plus AVX2/AVX-512 siblings where applicable, `nnue/koi.nnue`,
    `book/koi.bin`, docs, and licenses); developer tools and test binaries stay in
    source builds.
  - Implemented non-blocking transposition-table resize with deferred reclamation,
    isolated `GameState` implementation details, extracted worker pools and option
    catalogs, and enforced architecture boundaries in CTest (`koi_architecture_boundaries`).

## Strength

- **Self-play progression over the v1.1.5 search baseline (`mac-mini` arm64, promoted h128 net, `Hash=64`, `Threads=1`):**
  - Phase 1 (`e77dba9` vs `6fc1255`): **+544.7 Elo** at `1+0` (60 games, 95.83 %, LLR +20.05 `accept`), **+489.9 Elo** at 200 ms/move (80 games, 94.38 %).
  - Phase 2 (`5f1d82a` vs `e77dba9`): **+30.5 Elo** at 200 ms/move (80 games, 54.37 %).
  - Phase 4 (`51ba6e6` vs `5f1d82a`): **+110.8 Elo** at `1+0` (201 games, 65.42 %, LLR +2.96 `accept`), **+117.2 Elo** at 200 ms/move (80 games, 66.25 %).
- **Search depth and node efficiency (`Threads=1`, cold hash):**
  - Middlegame benchmark (`r1bq1rk1/ppp2ppp/2np1n2/2b1p3/2B1P3/2NP1N2/PPP2PPP/R1BQ1RK1 w - - 4 8`):
    depth 6 visited nodes dropped from `21,416,117` to **`70,881`** (**302.1x** reduction);
    average `1+0` match search depth rose from **`5.27`** to **`11.46`**.

## Compatibility and upgrade notes

- **NNUE remains the default and required boot evaluator** unless `KOI_EVALUATOR=hce`
  is set in the environment. Release archives bundle the promoted h128 network at
  `nnue/koi.nnue`, discovered automatically at startup.
- **`EvalMode` option added** (`nnue` default, `hce`) for switching between the
  promoted NNUE network and the clean classical evaluator at runtime.
- **GPU NNUE removed.** Koi is CPU-only on all platforms; the `GpuNnue` option is
  no longer advertised.
- **Engine-only release archives.** Developer CLI tools (`koi-bench`, `koi-replay`,
  `koi-perft`, `koi-eval-features`) are no longer bundled in release zips/tarballs;
  build from source when running developer benchmarks or test suites.
- **Optional assets:** `book/koi.bin` (custom CC0 Lichess-database Polyglot book)
  is included in release archives; Syzygy tablebases placed in `syzygy/` beside
  the executable are now auto-detected when `SyzygyPath` is unset.

## Assets

- `koi-engine-v1.1.6.zip` (Windows x64)
- `koi-engine-v1.1.6-linux-x86_64.tar.gz`
- `koi-engine-v1.1.6-macos-arm64.tar.gz`
- A `.sha256` sidecar for each archive.

Every archive carries the engine binaries, the promoted network at
`nnue/koi.nnue`, the custom CC0 Polyglot book at `book/koi.bin`, the installation
notes, required licenses, and a `package.json` manifest (schema
`koi-engine-package-v1`, version `1.1.6`, per-file SHA-256 hashes, network/book
inclusion flags, and source provenance including the gated-network report hash).

## Known limitations

- `UCI_LimitStrength`/`UCI_Elo` are not implemented (external anchors are used
  for measurement); `StrengthMode` remains a compatibility no-op.
- Syzygy tablebase data is not packaged.
